# Software FJ

## Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado legítimamente por **Luis Miranda** para la implementación de Programación Orientada a Objetos (POO) en Python, aplicando abstracción, herencia, polimorfismo, encapsulación y manejo avanzado de excepciones.

**Luis Miranda**

# Descripción del Proyecto

El sistema permite gestionar:

- Clientes
- Servicios
- Reservas
- Procesamiento de operaciones
- Manejo de errores y logs

Todo el sistema fue desarrollado sin bases de datos, utilizando únicamente:

- Objetos
- Listas
- Archivos de logs

---

# Tecnologías Utilizadas

- Python
- Visual Studio Code
- GitHub
- Programación Orientada a Objetos
- Manejo avanzado de excepciones

---

# Conceptos Aplicados

## Abstracción
Uso de clases abstractas:
- Entidad
- Servicio

## Herencia
Clases derivadas:
- ReservaSala
- AlquilerEquipo
- Asesoria

## Polimorfismo
Redefinición del método:
- calcular_costo()

## Encapsulación
Uso de atributos privados y propiedades en:
- Cliente

## Manejo de Excepciones
Implementación de:
- try
- except
- else
- finally
- excepciones personalizadas
- encadenamiento de excepciones

---

# Funcionalidades del Sistema

- Registro de clientes
- Validación de datos
- Creación de servicios
- Procesamiento de reservas
- Confirmación y cancelación
- Registro automático de errores
- Continuidad del sistema ante fallos
